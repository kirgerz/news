ЗАПУСК ВТОРОГО САЙТА

1. Распакуйте архив целиком. Откройте PowerShell в папке news-portal рядом с файлом artisan.

2. Требуется PHP 8.4.1 или новее с расширениями Laravel и pdo_pgsql, а также запущенный PostgreSQL.
   На исходном компьютере использовался PHP 8.5.
   Папка vendor с зависимостями уже включена в архив.
   При проблемах с зависимостями выполните composer install, используя composer.lock.
   Устанавливать npm-пакеты и запускать Vite для этого сайта не требуется.

3. Создайте пустую базу в PostgreSQL, например news_portal.
   Можно через pgAdmin либо SQL:
   CREATE DATABASE news_portal;

4. Создайте файл настроек:
   Copy-Item .env.example .env

5. Откройте .env и укажите данные СВОЕГО PostgreSQL:
   DB_CONNECTION=pgsql
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_DATABASE=news_portal
   DB_USERNAME=postgres
   DB_PASSWORD=ваш_пароль

   Обычно порт PostgreSQL — 5432. В примере .env.example стоит 5433,
   поскольку на исходном компьютере база работала через Docker на этом порту.
   Для запуска по стандартному адресу также задайте:
   APP_URL=http://127.0.0.1:8000

6. Из папки проекта выполните по очереди:
   php artisan key:generate
   php artisan config:clear
   php artisan migrate --seed
   php artisan serve

7. Откройте адрес, напечатанный сервером. Обычно это http://127.0.0.1:8000.

АККАУНТ АДМИНИСТРАТОРА ПОСЛЕ ЗАПОЛНЕНИЯ БАЗЫ:
   Логин: admin
   Пароль: admin123

Обычная регистрация создаёт читателя. Администратор назначает роли в админке.
Повторный запуск AdminSeeder не сбрасывает пароль существующего аккаунта.

Если порт 8000 занят:
   php artisan serve --port=8001

В архиве нет личного .env, ключа приложения, пользовательских сессий,
логов и содержимого рабочей базы. Тестовые статьи создаются сидерами.
Не запускайте migrate:fresh на базе, в которой есть нужные данные.
